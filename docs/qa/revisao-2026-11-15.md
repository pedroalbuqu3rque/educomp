# Revisão de código — 15/11/2026

Revisão da versão enviada em `educomp(3).rar`. O trabalho foi feito em uma cópia local, sem publicar alterações e sem modificar o Supabase hospedado.

## Alterações

| Área | Ajuste |
| --- | --- |
| Legibilidade | Formatação consistente em TypeScript, TSX, CSS, testes e configurações. Remoção de 49 comentários explicativos nesses arquivos. |
| Manutenção | Prettier configurado, comandos de formatação e verificação no CI. Lint passa a rejeitar avisos. |
| Classificações | Tipos, etapas, eixos e anos escolares reunidos em `src/lib/materials/taxonomy.ts`, evitando listas duplicadas entre busca e envio. |
| Dados de teste | Catálogo de exemplo usado pelos testes movido de `src/lib/library/demo-materials.ts` para `tests/fixtures/materials.ts`. |
| Moderação | Denúncias de comentários do acervo editorial agora recuperam título e identificador de `catalog_examples`. Antes, a consulta tratava todo comentário como pertencente à tabela `materials`. |
| Requisições | Validação de origem e leitura limitada do corpo reunidas em `src/lib/http/request.ts`. JSON e formulários multipart interrompem a leitura ao exceder o limite, inclusive sem `Content-Length` confiável. |
| Foto e envio | Falhas inesperadas retornam uma resposta JSON compreensível para os formulários. |
| Downloads | Após login solicitado por uma rota de arquivo, o usuário retorna à ficha do material. |
| Mensagens | Removidas instruções de migrations e `.env.local` das mensagens apresentadas ao usuário. |
| Notificações | O painel distingue carregamento, indisponibilidade e ausência de notificações não lidas. |
| Interface | Páginas de erro e de conteúdo não encontrado seguem as cores e os botões do EduComp. Rolagem suave respeita a preferência por movimento reduzido. |
| Limpeza | Removidos `gitattributes` duplicado, `APLICAR-SEGURANCA.txt`, geometria antiga sem uso e estilos obsoletos de compartilhamento e página provisória. Corrigida propriedade sem uso no painel de arquivos. |
| Documentação | README simplificado e controle de implementação atualizado. |

As exceções da regra de imagens do Next continuam restritas aos componentes que usam ícones exportados, imagens públicas ou prévia local. Elas foram movidas para a configuração do ESLint, sem desativar a regra no projeto inteiro.

O histórico SQL foi preservado, inclusive seus comentários. Os comentários e referências de `next-env.d.ts` são gerados pelo Next.js e também foram preservados. Esta revisão não exige migrations novas.

## Aplicação da revisão

O ZIP contém o projeto completo em `educomp/`, sem `.git`, `.env.local`, dependências ou arquivos de build.

Para conferir antes de substituir sua pasta de trabalho:

1. Extraia o ZIP em uma pasta nova.
2. Copie o seu `.env.local` para a pasta `educomp` extraída.
3. Rode `npm.cmd ci` e `npm.cmd run dev` nessa pasta.

Para integrar à pasta já vinculada ao Git, faça um commit ou backup antes. Substitua `src` e `tests` pelas pastas revisadas e copie as configurações, a documentação e os arquivos de dependências. Preserve sua pasta `.git` e o seu `.env.local`. Exclua os arquivos removidos listados acima; uma cópia por cima não os remove automaticamente. Não recrie `public/biblioteca/arquivos`.

Execute as verificações do README antes de enviar ao GitHub. Não é necessário executar scripts SQL para aplicar esta revisão.
